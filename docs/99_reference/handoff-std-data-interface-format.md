## 0. 一句话任务

把**数据结构的固定格式**与**接口的固定格式**升为 STD 通用规范，**所有设计文档**的数据/接口章节统一采用；并按文档类型规定各自应描述的数据结构与接口（见 §3 表）。请按下文 **P0/P1** 修改模板与配套设施。

## 1. 背景与基线

- STD 已有多处"数据 / 接口"章节：`design.software-system`、`design.system-mechanism`（§4 数据结构设计 / §5 接口设计 / §14.3）、`design.subsystem`、`design.definition`（§6 / §9）、`design.implementation`、`design.data-dictionary`（§3 Entity Catalog / §4 Field Dictionary）、`contracts.specification`。但**格式各异、粒度不一**，消费方无法据此直接编码或写用例。
- LLMTier 在 `libdiag-design.md` 试点：§9.1 数据结构（11 个，4 段）、§9.2 接口（15 个，6 段）、§6 数据模型（6 表，4 段）、§5.3 文件间接口（6 段）。一次 correctness review 据此**逐项对照代码**，纠正了可空性等 7 处——证明该格式**可校验、可交付**。
- 原则沿用：**数据结构与接口分开描述**（被复用的结构只描述一次）、**同一对象只有一处字段级 authority**、**粒度自外向内**。

## 2. 建议清单

### P0 — 统一两套固定格式（全局）

| # | 位置 | 问题 | 建议 |
|---|---|---|---|
| **F1 数据结构固定格式** | 所有设计文档的"数据结构/数据模型/数据字典"节 | 各文档字段描述格式不一，字段级信息（类型/必填/范围/不变量）常缺失 | 统一定义 **4 段**：`定义` / `字段`（逐字段一行：`名称`：`类型`｜必填性｜范围·枚举·单位｜说明）/ `不变量` / `来源`。见 §4.1 |
| **F2 接口固定格式** | 所有设计文档的"接口/契约/机器契约"节 | 接口缺逐参数/逐字段/返回值条件，消费方无法写用例 | 统一定义 **6 段**：`功能` / `输入`（逐参数一行）/ `输出`（数据结构 ID）/ `返回值`（每条件一行）/ `统计 · 日志` / `数据库`。见 §4.2 |
| **F3 分离与复用规则** | 全文 | 结构被逐接口重复描述 | 数据结构与接口**分节**；被复用结构只在一处描述，接口用 **ID 引用**；字段级 authority 唯一（`interfaces/*` 或 `design.data-dictionary`），设计文档与之一致 |
| **F4 领域变体** | 硬件/FPGA 模板 | 软件口径不适用 | 结构相同；接口后两段换 `时序 · 资源` / `持久化 · 寄存器`；字段行以 `位宽 / 端序 / 复位值` 替代软件类型 |

### P0 — 各模板必填语义与分工

| # | 位置 | 问题 | 建议 |
|---|---|---|---|
| **D1 `design.data-dictionary`** | §3/§4/§5/§6 | 已承载字段级 authority，但未规定用固定格式、也未声明它与其它设计文档的关系 | 明确它是**字段级 authority**，并与 §4.1 数据结构格式对齐；其它设计文档的数据结构**引用**它，不复制两份 |
| **D2 `design.definition`（模块）** | §6/§9 | §6 数据模型、§9 接口的字段要求不完整；"文件间接口"无固定格式 | §6 用 F1；§9 用 F2（对外接口）+ 文件间接口（F2）；对外可复用结构放在数据结构节、只描述一次 |
| **D3 `design.implementation`（ISD）** | §4/§5 | 内部私有数据与函数契约格式不统一；易与模块设计重复 | 内部私有数据（文件内类型/内存对象/表/状态机）用 F1；函数契约沿用现字段，并**引用**模块设计的数据结构 ID；接口段落的"数据库"落到具体表列 |
| **D4 `design.system-mechanism`** | §4/§5/§14.3 | 有"数据结构设计/接口设计/责任单元间接口契约"，但格式不统一 | §4 用 F1（状态/消息/阶段）；§5 用 F2；§14.3 用 F2 |
| **D5 `design.software-system`** | 数据/接口节 | 系统级边界数据与接口，粒度未定，易与模块设计重复 | 用 F1/F2 但**粗粒度**（跨边界必需字段）；接口指向 `contracts.specification` 权威，不复制 wire 细节 |
| **D6 `design.subsystem` / `design.system`** | 数据/接口节 | 同上 | 子系统：对外暴露数据对象用 F1、对外接口用 F2；架构级：仅**对象/接口目录索引**（名称/owner/权威文档/方向），不展开字段 |
| **D7 `contracts.specification` / `interfaces.control`** | 数据/接口节 | —— | 机器契约用 F1/F2（字段级权威 + 端点契约），作为下游设计文档引用的 authority |

## 3. 每种设计文档应描述的数据结构与接口

| 设计文档（template） | 应描述的**数据结构** | 应描述的**接口** | 粒度 |
|---|---|---|---|
| 架构设计 `design.system` | 平台级**对象/实体目录索引**（名称、owner、权威文档） | **系统间接口索引**（谁↔谁、方向、权威契约 ID） | 索引级 |
| 软件系统设计 `design.software-system` | **系统级对外数据对象**（跨边界顶层对象：请求/响应信封、事件、资源表示） | **系统边界接口**（对外/跨系统；责任模块 + 权威契约引用） | 跨边界必需字段 |
| 系统机制设计 `design.system-mechanism` | 机制**状态与消息**（状态机状态、消息/事件类型、判定事实、阶段） | **参与方交互**（每步发起/接收方、输入、输出、失败出口） | 机制内部必需 |
| 子系统设计 `design.subsystem` | 子系统**对外暴露数据对象**（类型、枚举、状态） | **子系统对外接口**（被谁调用、提供/消费、依赖方向） | 子系统边界 |
| **模块/组件设计** `design.definition` | 模块**对外可复用结构**（视图/DTO/枚举/开关）：F1，复用只描述一次 | **模块对外接口**（F2）+ **文件间接口**（F2） | 字段级（对外） |
| **数据字典** `design.data-dictionary` | **字段级权威**（Entity/Field/Enum/Key/Ownership/序列化/持久化）：F1 | 只被接口**引用**，不描述接口 | 字段级（权威） |
| **实现规格（ISD）** `design.implementation` | 模块**内部私有数据**（文件内类型/内存对象/表/状态机）：F1 | **关键函数实现契约**（签名/参数/成功·错误返回/前置/副作用/幂等/并发）；对外结构**引用模块设计 ID** | 函数级（私有） |
| 硬件设计 `design.hardware` | 板级**寄存器/接口信号/时序参数**（F1 变体） | 板级**连接器/总线协议/引脚**（F2 变体） | 板级 |
| FPGA 设计 `design.fpga` | RTL **接口信号/寄存器 map/状态**（F1 变体） | RTL **模块端口/握手协议**（F2 变体） | 端口级 |
| 接口契约 `contracts.specification` / `interfaces.control` | **机器可读 wire Schema**（字段/类型/必填/范围/编码/版本）：F1 | **端点/方法契约**（路径/方法/请求/响应/状态码/错误码）：F2 | 字段级（权威） |

## 4. 两个固定格式（精确）

### 4.1 数据结构（4 段）

```markdown
#### <Data ID> · `<名称>`
- **定义**：<一句话语义、用途、边界>
- **字段**：
  - `名称`：`类型`｜必填性（必填 / 可空）｜范围·枚举·单位｜说明
- **不变量**：<跨字段约束、默认、唯一性、寿命>
- **来源**：<定义/产出该结构的权威位置（文件·symbol 或 schema 路径）>
```

### 4.2 接口（6 段）

```markdown
#### <Interface ID> · `<签名 / 操作名>`
- **功能**：<做什么、为谁、边界>
- **输入**：
  - `名称: 类型`｜必填·默认｜范围·枚举｜说明
- **输出**：<数据结构 ID（§数据） / 字节流 / 无>
- **返回值**：<每条件一行：`<条件> → <值>`；含错误码与其触发条件>
- **统计 · 日志**：<对外可见的统计/日志口径与触发；无则 `无`>
- **数据库**：<何种情况改哪些表/列（或“只读”“无”）>
```

- 时间统一 RFC3339（UTC，毫秒）；`?` 表示可空。
