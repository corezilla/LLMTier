## 本轮修复的问题

### 1. API Smoke Test（tools/api_smoke_test.py）
新建综合 API 测试，覆盖所有外部端点：
- Public: /healthz, /readyz, /v1/models
- Data: /v1/responses, /tier/v1/usage
- Admin CRUD: providers, deployments, service-levels, runtime

**修复的 bug：**

- /tier/v1/usage 缺少 RFC3339 时间参数

### 2. ST-12 Embedding Test
**问题**：原测试硬编码 `127.0.0.1:9100`，这是错误的架构假设。

LLMTier 是**局域网服务**，测试必须用 LAN IP。`127.0.0.1` 测的是本机进程通信，不是 LAN 服务。

**修复内容：**
- Endpoint: `http://127.0.0.1:9100` → `http://192.168.1.9:9000/v1`（m5air OMLX）
- 去掉 provider 里多余的 `usage` 字段
- 修复 `_omlx_key()` 里的 operator precedence bug
- Model: bge-m3（1024 维）

## 暴露的架构层面问题

### Review 缺少架构检查项
PR review 只检查代码逻辑，没检查架构设计：
- LLMTier 是 LAN 服务，测试应该用 LAN IP
- Provider endpoint 指向哪个环境（m5mac/m5air）
- 测试依赖的服务在目标环境是否可用
